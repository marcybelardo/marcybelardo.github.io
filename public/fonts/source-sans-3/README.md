# Source Sans 3

Unmodified variable WOFF2 fonts from Adobe's Source Sans repository, pinned to
commit `87b37a2daaed80fcb8e8ccb0085c4d72ddade12e`:
https://github.com/adobe-fonts/source-sans/tree/87b37a2daaed80fcb8e8ccb0085c4d72ddade12e/WOFF2/VF

The upstream `SourceSans3VF-Upright.ttf.woff2` and
`SourceSans3VF-Italic.ttf.woff2` files are stored here without the `.ttf` portion
of their filenames. Both support weights 200–900. See LICENSE.md for the
SIL Open Font License and copyright notice.

`src/styles/global.css` serves these files locally with `font-display: swap`.
